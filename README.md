# 📘 Student Management System

## 📌 Overview
This is a *Spring Boot + MySQL web application* for managing student records.  
It allows you to perform *CRUD operations*:  
- Add Student  
- View Students  
- Update Student  
- Delete Student  

The project demonstrates how to integrate *Spring Boot, Spring Data JPA (Hibernate), Thymeleaf, and MySQL* to build a real-world web application.  

---

## 🛠 Tech Stack
- *Backend Framework*: Spring Boot (Java 17)  
- *Database*: MySQL 8+  
- *ORM*: Spring Data JPA (Hibernate)  
- *Frontend*: Thymeleaf templates (HTML)  
- *Build Tool*: Maven  
- *Server*: Embedded Tomcat
